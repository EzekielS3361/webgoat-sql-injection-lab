# SQL Injection Demonstration Using OWASP WebGoat & Docker

## Project Overview

This project documents my hands-on experience
learning about SQL injection vulnerabilities
using OWASP WebGoat.

The goal is to understand how SQL injection works, demonstrate the vulnerability in a controlled environment, and explore techniques developers can use to prevent these attacks.

## Tools & Technologies

- Docker Desktop
- OWASP WebGoat
- SQL
- Windows PowerShell
- GitHub

## Learning Objectives

- Understand basic SQL commands and database queries.
- Learn how SQL injection vulnerabilities occur.
- Complete introductory SQL injection exercises in WebGoat.
- Document testing procedures and observations.
- Understand how parameterized queries help prevent SQL injection.

## Lab Environment

WebGoat was deployed locally using Docker Desktop on Windows.

The application was accessed through:

http://127.0.0.1:8081/WebGoat

All security testing is performed within an intentionally vulnerable local training environment.
